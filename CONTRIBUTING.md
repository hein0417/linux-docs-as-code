# Contributing

Contributions are welcome, from typo fixes to new tutorials.

1. Fork the repository and create a branch.
2. Edit or add `.adoc` files in the main folder of the repository.
3. Build locally to check your changes (see the README).
4. Open a pull request with a short description of what you changed and why.

## Style

- Use clear, short sentences and the second person ("you").
- Start procedure steps with a verb.
- Put commands and file names in code formatting.
